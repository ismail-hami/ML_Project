## Overview

EMSI_IA_Visualizer_3D is a standalone desktop application that provides interactive 3D visualizations of six Machine Learning algorithms. Developed for a 3rd-year Computer Science project at EMSI.

## Algorithms Included

- Multiple Linear Regression – 3D regression plane with point cloud
- K-Means Clustering – Three 3D projections of cluster results
- Random Forest – Feature importance, 3D confusion matrix, error scatter
- ARIMA Time Series – 3D ribbon forecast with confidence interval
- Neural Network (MLP) – 3D loss surface and real vs predicted scatter
- Stratified K-Fold Cross-Validation – Accuracy per fold, F1 surface, training time, ribbon comparison

## Technologies

Python, Tkinter, Matplotlib, Scikit-learn, Statsmodels, NumPy, Pillow, PyInstaller

## Installation

1. Clone the repository:
   git clone https://github.com/ismail-hami/ML_Project.git
   cd ML_Project

2. Install dependencies:
   pip install -r requirements.txt

3. Run the application:
   python AlgoML_3D.py

## Executable Version

A Windows standalone executable (.exe) is available in the Releases section. No Python installation required.
